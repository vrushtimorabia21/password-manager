# 🔐 Password Manager

A simple Password Manager built using **Python and Tkinter**. It generates random passwords and saves website login details in a local text file.

## ✨ Features

* Generate random passwords
* Enter website and email/username
* Save login details
* Confirmation before saving
* Simple Tkinter GUI

## 🛠️ Technologies

* Python
* Tkinter
* Random module

## ▶️ How to Run

1. Install Python.
2. Keep `logo.png` in the same folder as the Python file.
3. Run:

```bash
python main.py
```

## ⚠️ Note

This is an educational project. Passwords are stored as plain text in `data.txt`, so it should not be used for storing real passwords.
